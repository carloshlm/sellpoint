SellPointy tiene tres planes. Cada uno trae todo lo del anterior y agrega lo
suyo. Los capítulos de este manual llevan la misma marca: *Desde Basic*, *Desde
Pro* o *En Plus*.

| | Basic | Pro | Plus |
|---|:---:|:---:|:---:|
| Usuarios | 3 | 6 | 20 |
| Sucursales | 1 | 4 | 10 |
| Punto de venta y tickets | ✓ | ✓ | ✓ |
| Turno de caja con arqueo | ✓ | ✓ | ✓ |
| Ticket con tu logo, en 58 u 80 mm | ✓ | ✓ | ✓ |
| Reportes y exportarlos a Excel | ✓ | ✓ | ✓ |
| Gastos | ✓ | ✓ | ✓ |
| Control de inventario | — | ✓ | ✓ |
| Entradas, salidas y kardex | — | ✓ | ✓ |
| Traspasos entre sucursales | — | ✓ | ✓ |
| Cotizaciones | — | ✓ | ✓ |
| Productos compuestos: recetas y kits | — | ✓ | ✓ |
| Compras | — | ✓ | ✓ |
| Órdenes de compra y recepciones parciales | — | — | ✓ |
| Lotes y caducidades | — | — | ✓ |
| Subcatálogos y campos propios | — | — | ✓ |
| Roles personalizados | — | — | ✓ |

**Sin control de inventario, en Basic la venta nunca se detiene**: puedes cobrar
aunque no tengas existencias cargadas. Cada venta descuenta del inventario
igual; si después cambias a Pro, lo que haya quedado en negativo se corrige con
un inventario físico (capítulo 25).

## Precios en México

Precios de lista en pesos mexicanos (MXN):

| | Basic | Pro | Plus |
|---|---:|---:|---:|
| Mensual | $199 | $349 | $499 |
| Anual | $1,990 | $3,490 | $4,990 |

El plan anual cuesta lo mismo que diez meses: dos meses gratis. Los precios
vigentes para tu negocio siempre los ves en **Mi plan** › **Ver planes**
(capítulo 34).

## Además de los tres planes

- **La prueba.** Toda cuenta nueva empieza con 14 días gratis con todo lo del
  plan Plus.
- **Premium.** Todo lo de Plus, sin límite de usuarios ni de sucursales, más
  módulos hechos a la medida de tu negocio. El precio se acuerda con cada
  cliente; para pedirlo, presiona **Me interesa** en Premium, en **Ver planes**.
- **El modo gratuito.** No es un plan que se contrate: es donde queda una cuenta
  cuando termina la prueba o vence el plan sin pago. Puedes consultar todo y
  vender hasta 10 veces al día, pero no crear ni editar. Nada se borra
  (capítulo 34).

## Si cambias de plan

- **A uno mayor**: lo nuevo se enciende en cuanto se registra el pago.
- **A uno menor**: no se borra nada ni se suspende a nadie. Lo que el plan nuevo
  no incluye queda con candado en el menú o deja de aparecer, y los límites de
  usuarios y sucursales solo se revisan al crear uno nuevo.
